# EBP3901-A01 测试报告

## 一、测试概述

- **测试板卡** ：EBP3901-A01   
- **测试目标**： 验证使用 RuyiSDK 统一工具链管理，在 EBP3901-A01 上进行 Hello World 编译、烧录和运行的完整流程   

## 二、测试执行过程  

### 2.1 安装 ruyi 包管理器    

```bash
sudo apt update; sudo apt install -y wget tar zstd xz-utils git build-essential

wget  https://mirror.iscas.ac.cn/ruyisdk/ruyi/tags/0.48.0/ruyi-0.48.0.amd64
chmod +x ruyi-0.48.0.amd64
sudo cp -v ./ruyi-0.48.0.amd64 /usr/local/bin/ruyi
```
### 2.2 安装 GCC 和 LLVM 工具链
```bash
ruyi update
ruyi install gnu-plct llvm-plct
```

### 2.4  安装  ESWIN  专属工具链
手动导入了  ESWIN  官方提供的  eswin-riscv64-elf-gcc 工具链并集成至  Ruyi  管理目录。     
从官网下载EBP3901-A01 离线安装包， 把EBP3901-A01工具链集成到ruyisdk    
安装集成的eswin工具链       
```bash
ruyi install toolchain/eswin-riscv64-elf-gcc
```

### 2.5 创建并激活虚拟环境
```
mkdir -p ~/venv-eswin-gcc/bin

cat > ~/venv-eswin-gcc/bin/ruyi-activate <<'EOF'
#!/bin/sh
export PATH="$HOME/.local/share/ruyi/binaries/x86_64/eswin-riscv64-elf-gcc-1.0.0/bin:$PATH"
echo "activated venv-eswin-gcc"
EOF

chmod +x ~/venv-eswin-gcc/bin/ruyi-activate

source ~/venv-eswin-gcc/bin/ruyi-activate
hash -r
which riscv64-unknown-elf-gcc
riscv64-unknown-elf-gcc -v
```
